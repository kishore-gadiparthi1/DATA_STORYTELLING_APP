# Data Storytelling Application: Retail Operations Analysis

## Project Overview
This repository contains a Data Storytelling web application built using Python and Streamlit. Unlike a standard dashboard, this application guides the user through a structured data narrative, exploring supermarket transaction patterns, analyzing operational highlights, and delivering data-driven business recommendations.

The app uses a localized `sales.csv` dataset to ensure stable, offline-capable performance.

---

## Data Narrative Structure & Requirements Met

* **1. Introduction to the Dataset:** A clear textual introduction explaining the origin of the data, the business context of the supermarket branches, and the overarching objectives of the analysis.
* **2. Exploratory Data Analysis (EDA) & Insights:** * **Department Revenue Contribution:** A Plotly interactive bar chart visualizing total sales across product lines, accompanied by a analytical narrative detailing top-performing categories and underperforming sectors.
  * **Consumer Payment Preferences:** A Plotly pie chart displaying payment method distributions, paired with structural insights highlighting the consumer shift toward digital transaction modes (E-wallets and Credit Cards).
* **3. Strategic Conclusions & Recommendations:** Concludes the data journey with clear, actionable business strategies concerning inventory allocations, point-of-sale infrastructure modernization, and targeted marketing campaigns.
